# DOIT Tech Island｜產業技術島

一座島一個產業領域。用一張 3D 海圖，看半導體及光電、資通訊、機械、運輸、生醫、材化、淨零科技七座島上，各在研發什麼。

**群島 → 島 → 區 → 街 → 技術**：每座島是一個產業領域，島上每一區是一個研發方向（一章），區裡的每棟房子是一個研發主題；機器人區有 6 條街、17 項關鍵技術。Dr. T 搭著熱氣球一路導覽。

內容以《2025/2026產業技術白皮書》（經濟部產業技術司）為基礎整理，和「產業技術星圖」使用同一套資料格式與 17 項關鍵技術。

## 快速開始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 建置到 dist/
npm run check      # 內容完整性檢查
```

網站是靜態檔案，不需要資料庫；唯一的伺服器程式是選用的自然男聲（`api/tts`）。

## 部署到 Vercel

1. Vercel → Add New → Project → 匯入這個 repo（Framework 會自動辨識為 Vite，設定都在 `vercel.json`）。
2. 按 Deploy。之後每次 push 到 `main` 都會自動重新部署。

Vercel 免費方案（Hobby）限個人、非商業用途；正式對外的商業服務請用 Pro。

## 島上有什麼

| 層級 | 是什麼 | 在海圖上 |
|---|---|---|
| 島 | 產業領域（7 座） | 一群六角形地塊，顏色代表領域 |
| 區 | 研發方向（20 區） | 7 塊地組成的一朵花，中間是地標（晶片堆疊、燈塔、機械手臂、風機…） |
| 研發主題 | 每一區的研發主題（77 個） | 區裡的房子 |
| 街、技術 | 機器人區的 6 條街、17 項關鍵技術 | 亭子，屋頂顏色代表街 |
| 海路 | 不同島之間相連的技術 | 海上的虛線航道 |

每一區的說明欄有：簡介、為什麼重要、研發重點、研發主題、科技專案，以及和其他區相連的技術。

## 語音朗讀與大字

* 每個欄位都有「朗讀」按鈕，區與技術另有「朗讀全文」；Dr. T 的導覽也可以「唸給我聽」。正在朗讀的段落會亮起，換頁就停止。
* **自然男聲（建議）**：在 Vercel 的 Environment Variables 加上 `AZURE_SPEECH_KEY` 與 `AZURE_SPEECH_REGION`，網站會用 Azure 神經語音 `zh-TW-YunJheNeural`（溫暖的臺灣男聲）朗讀，每台手機聽到的都是同一個聲音。錄音由 `api/tts` 產生、存在 Vercel 的 CDN，同一段文字只合成一次；Azure Speech 免費方案（F0）每月 50 萬字元，整座島的文字遠低於此。可調整 `TTS_VOICE`、`TTS_RATE`（預設 `0%`）、`TTS_PITCH`（預設 `0%`）。
* **沒有設定時**：使用訪客裝置內建的國語語音：男聲優先，接著是自然／神經語音（Edge 的「Online (Natural)」、Apple 的增強版、Google 的線上語音）與臺灣國語，舊式的電腦語音排在最後；音調維持語音本身，語速預設 1.2 倍。多數手機內建的臺灣國語只有女聲。
* 「聲音」可以自己挑聲音（點一下就試聽）和語速（慢一點 1 倍／正常 1.2 倍／快一點 1.4 倍／更快 1.6 倍），選擇會記在這台裝置上。
* 內文 17px 以上，海圖上的地名都是可以直接點的按鈕，所有按鈕至少 40–44px 高。
* 手機上，說明欄從下方升起，可以「放大閱讀」或收起來看海圖；「目錄」列出所有的島、區與技術，不用操作 3D 也能找到每一頁。

## 檔案

```

│  islands.js        七座島與二十區：簡介、研發重點、研發主題、科技專案、地標
│  technologies.js   17 項關鍵技術（與產業技術星圖相同）

│  sources.js        原文摘錄；每段說明文字的 refs 指向這裡
shared/speech.js     朗讀規則：哪些欄位可以唸、符號怎麼唸
src/
│  data/world.js     島、區、街、技術的索引、搜尋、關係
│  scene/            Three.js 海圖：layout（六角格與花形區）、islands、landmarks、sea（等深線）、routes（海路）、balloon（Dr. T）、World（相機、點選、地名）
│  components/       說明欄、地名、Dr. T、搜尋、目錄、資料來源
│  state/route.js    網址（#/district/robot）＝目前位置，可分享、可上一頁
api/tts/             Vercel Function：自然男聲（有設定 Azure 金鑰時）
server/              朗讀文字（只唸網站自己的內容）與 Azure 語音
scripts/
│  validate.mjs      完整性檢查：引用都存在、研發主題與科技專案和原文逐條一致
│  verify-sources.mjs 原文摘錄與 PDF 文字逐字比對
```

## 資料的可信度

每段說明文字都是 `{ t, type, refs }`：`SOURCE` 依原文改寫，`DERIVED` 是產業技術島自己的整理或歸納（例如每座島的一句話介紹），`refs` 指向 `sources.js` 的原文摘錄。說明欄最下方的「資料來源」可以打開對應原文。

`npm run check` 會確認每一區的研發主題、科技專案和原文逐條相同；`npm run verify -- pages.json` 會把每段摘錄和白皮書 PDF 的文字逐字比對。欄位是空的時候，畫面顯示「資料持續建構中」，不會為了看起來完整而補寫。
